# NCB200 — OpenNCB CHI↔AXI Non-Coherent Bridge 主体(顶层结构装配)

> 设计源:OpenNCB `NCB200`(CHI 从口 ↔ AXI 主口 非一致桥主体)
> golden:`/home/eda/xs-env/G0-canonical/golden-rtl/NCB200.sv`(23834 行,1234 端口)
> 可读核:`rtl/uncore/NCB200.sv`(`xs_NCB200_core`)
> FM 包装:`rtl/uncore/NCB200_wrapper.sv`(golden 同名 `NCB200` 扁平端口 → `u_core`)
> 生成器:`scripts/gen_ncb200.py`(从 golden 顶层机械派生 core / wrapper / UT / Makefile)
> 层次:XSTop → OpenNCB → **NCB200** → 16 子模块 → 9 孙模块

## 关键定性:NCB200 是纯结构装配壳(无状态、无数据通路)

golden `NCB200`(顶层模块本身)统计:

| 指标 | 值 |
|------|----|
| always 块 | **0** |
| reg 声明 | **0** |
| `_GEN_` / `_T_` | 0 / 1 |
| assign | 1144(其中 **1142 是纯透传** `assign a = b`,仅 2 个含运算符) |
| wire 声明 | 4489(模块间互连网) |
| 子模块实例 | 16 |

即:顶层模块**没有自己的时序逻辑,也没有数据通路**——它是一个把 16 个叶子子模块
连起来的**接线壳**。全部真实逻辑住在子模块里(78313 行)。这两个含运算符的 assign
也只是平凡归约:

```
assign io_chi_txsactive = ~_uTransactionFreeList_io_empty;
assign debug_valid      = |{全部 1141 个 debug_reason_* 位};   // _debug_valid_T_31 拼接
```

因此「重写」对本层而言 = **忠实(bug-for-bug)地重建 golden 的连接关系**;顶层没有
`_GEN_`/`_T_` 数据通路可化简(golden 本就是 firtool preamble 之外全手写的 OpenNCB
Verilog)。核内 instance+assign 区与 golden 逐字(去空白)一致 = 忠实装配。

## FM 签核方法(strict-clean,零黑盒)

- **impl 侧** = `xs_NCB200_core`(可读接线核)+ `NCB200_wrapper`(golden 名扁平端口 → u_core)。
- **两侧全子树 elaborate**:16 子 + 9 孙(共 25 个 golden 逻辑模块)同时进 ref 与 impl。
  因**无厂商 SRAM**,**任何模块都不作黑盒**——满足 `signoff-strict`(strict 下有黑盒即 PARTIAL)。
- 由于子/孙在两侧是**同一份 golden 源**,它们在各自边界恒等;FM 真正证明的是
  **顶层接线** `xs_NCB200_core` ≡ golden `NCB200` 的连接关系(bit 精确)。
  这是装配父的正确作用域(对照已绿 MMIOBridge/Slice/Prefetcher 的「逻辑 child 两侧 elaborate」)。
- `FM_MODE=signoff-strict`,`FM_MERGE_DUP=false`(重复叶子实例不合并),
  `FM_VERIFY_MATCHED_UNREAD_COMPARE_POINTS=true`(见下),`allow/NCB200.json` 四键全空。

### 实测(隔离 fm_shell,strict appvars;evidence `/tmp/ncb200-evidence/NCB200/`)
| 探针 | 黑盒 | 结果 | passing | failing | unmatched | unread |
|------|------|------|---------|---------|-----------|--------|
| 13-bbox(不给 9 孙) | 13 对称 | SUCCEEDED | 55195 | 0 | 0(0) | 0 |
| 全闭包 strict(补齐 9 孙) | **0** | SUCCEEDED | 56520 | 0 | 0(0) | **5208**(+84 常数reg) |
| 全闭包 + vmucp | **0** | SUCCEEDED | **61728** | 0 | 0(0) | **0**(仅 84 常数reg,无害) |

- 全闭包 strict 有 **5208 matched-unread DFF**:golden 子(uTransactionPayload 37248 /
  uTransactionQueue 8192 存储阵列)内**被写但读锥不达 NCB200 顶层输出**的 cone-dead 寄存器。
  两侧同款 golden 子 ⇒ 完美对称双射 `r:/.../<child>/reg ↔ i:/.../u_core/<child>/reg`。
- 开 `verify_matched_unread_compare_points=true`(vmucp)后 FM **实际逐位比较**这 5208 点,
  **全部转 passing**(DFF 54504→59712,0 failing)⇒ 证明**真等价、非 vacuous**。
  余 **84 Constant reg** 属常数死位,`fm_verdict.py` 的 `unread_nc` 正则不计入 ⇒ 不 gating。
- ∴ measured=**SUCCEEDED**,gate=**PASS**(需 main 把 NCB200 加入 vmucp 白名单)。
