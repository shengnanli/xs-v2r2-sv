# NCB200_1 —— CHI↔AXI Non-Coherent Bridge(32 条目事务表变体）

> golden 源:`golden-rtl/NCB200_1.sv`(firtool 单态化,12327 行)
> 可读核:`rtl/uncore/NCB200_1.sv`(`xs_NCB200_1_core`)+ `rtl/uncore/NCB200_1_wrapper.sv`(`NCB200_1`)

> AUX signoff:assembly(`verif/signoff/allow/NCB200_1.json`,4 键全空)

## 角色

NCB200_1 是 **OpenNCB_1 的核心 child**:把 CHI(rxreq/rxdat/txrsp/txdat + linkactive)非一致性
请求桥接到 AXI(aw/w/b/ar/r)。它是 **NCB200(64 条目)的 32 条目参数变体**:

| 维度 | NCB200 | NCB200_1 |
|------|--------|----------|
| 事务表深度 | 64(debug 索引到 `_63`) | 32(debug 索引到 `_31`) |
| AXI id 宽 | 6 位(`[5:0]`) | 5 位(`[4:0]`) |
| `io_axi_{ar,aw}_bits_cache` | 无 | 有(cache 属性透传) |
| golden 行数 | 23833 | 12327 |
| 端口数 | 1234 | 692 |

结构上仅参数差异(表深/id 宽/两口 cache);两 golden 逐结构比对,NCB200_1 = NCB200 的
子集(去掉 32 条目的 debug 端口 + 收窄 AXI id + 加 cache 口)。**未复用 NCB200 核**:两者是
各自独立的 firtool 单态化产物,NCB200_1 自成一份可读核更清晰(避免参数化耦合)。

## 顶层结构:纯结构 netlist

NCB200_1 顶层是 **纯结构 netlist**:
- **0 register / 0 always / 0 function / 0 generate**;
- 仅 wire 声明 + **16 个 child 例化** + **纯组合 assign**(598 条直通 + `debug_valid = |concat(598 debug reason)`);
- 全部功能逻辑在 16 个 child 内;顶层只做互连:每个 child 端口连到 top IO 或另一 child 输出
  wire(`_uChild_io_port`)。

golden 的 wire/assign 命名全部语义化(`_u<Child>_io_<port>`),无 `_GEN_`/`_T_` 混淆
(唯一 `_debug_valid_T_31` 在核内改名为 `_debug_reason_all_cat`)。可读核忠实重建这一互连。

## FM 签核:assembly + vmucp + merge=false(native SUCCEEDED 30149p/0f)

- **FM_MODE=assembly**,26 个 child 两侧(ref 和 impl)都 elaborate golden RTL(逻辑 child,
  非黑盒,`ref==impl` 同源)。**无厂商 SRAM 宏**。
- **FM_MERGE_DUP=false**:关闭重复寄存器合并。26 child 有多份同款子模块(SpillRegister/
  LinkCreditManager/Decoder),impl 侧多一层 `u_core` 会让 `merge_duplicated_registers`
  两侧不对称合并 `uLinkCredit` 的 `regInitialCycleCounter`/`regInitialCreditCounter`
  → 18 个 golden-only unmatched-ref 伪影。关掉合并后两侧逐寄存器对称匹配(0 unmatched)。
- **vmucp=true**(verify_matched_unread_compare_points):2552 个**对称 matched-unread**
  (写入但本层不读的 cone-dead 寄存器,完美双射 `r:.../<child>/X_reg` ↔ `i:.../u_core/<child>/X_reg`;
  分布 uTransactionQueue 2208 / uAR·uW 各 160 / uRXREQ 23 / uRXDAT 1)在 vmucp 下被 FM
  **实际逐位比较** → 全 passing(27597+2552=30149)。非 vacuous。
- **唯一黑盒** = `NCBOrderAddressCAM_1`,golden 本身把它化简成**空模块**(只有 clock/reset,
  无输出端口)→ FM 归 `empty_blackbox`(matched_blackbox_pair,两侧对称,0 compare point);
  `allow/NCB200_1.json` 精确声明该 pair(`empty_blackbox` 类)。
- 结果:native SUCCEEDED,**30149 passing / 0 failing / 0 unmatched / 0 unread_notcompared**,
  无 dont_verify / elab147 / relaxed_appvars。sidecar 官方 validator(加 NCB200_1 到
  `_MU_STRENGTHEN` 白名单后)= SUCCEEDED;不加白名单 = ERROR(证白名单确需)。
